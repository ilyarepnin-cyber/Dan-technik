Калькулятор стоимости (₽)

Итог ориентировочный; коммерческое предложение — после уточнения адреса/объёма.

Модель расчёта (пример для запуска):

  • База ₽/т по фракции: 0–5 = ₽950, 5–20 = ₽1 200, 20–40 = ₽1 100, 40–70 = ₽900.
  • Множитель зоны: Москва ×1.00, МО до 30 км ×1.08, 30–60 км ×1.15, 60–90 км ×1.25.
  • Скидки объёма: >50 т = −3%, >100 т = −6%.
